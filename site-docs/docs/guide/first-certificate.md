# 签发第一张证书

## 1. 创建渠道账户

「SSL 渠道账户」→ 新建账户，按渠道选择：

| 渠道 | 需要配置 |
|---|---|
| ACME | 目录 URL（默认 Let's Encrypt 生产）、联系邮箱、可选 EAB |
| 阿里云 | AccessKey ID/Secret、地域、申请人姓名/邮箱/电话 |
| 腾讯云 | SecretId/SecretKey、联系邮箱/手机、验证方式（DNS_AUTO 推荐） |

创建后点击「测试」验证凭据可用（ACME 账户将在此完成注册）。

## 2. 签发证书

「证书管理」→ 签发证书：

- **域名**：单个或多个（逗号分隔）；云厂商免费证书单次仅支持单个域名
- **渠道账户**：选择已测试的账户
- **验证方式**（仅 ACME）：HTTP-01（需 80 端口可达）或 DNS-01（需 DNS API 凭据）
- **部署目标**（可选）：签发成功后自动部署

签发为同步操作：ACME 渠道等待验证与签发（可达数分钟），云厂商渠道轮询申请状态。

## 3. 验证结果

- 证书列表显示状态（签发中/有效/即将到期/已过期/吊销/失败）与到期倒计时
- 详情页可查看 SAN、签发 CA、有效期、任务时间线（签发/续期/吊销记录）
- 支持下载证书/私钥（私钥下载需 operator 及以上角色，记录审计）

## 4. 常见问题

- **云厂商渠道提示"域名验证未完成"**：确认域名托管在对应云 DNS（DNS_AUTO 模式）或按指引手动添加 TXT 记录
- **ACME HTTP-01 失败**：确认管理服务器 80 端口公网可达（`acme.http01_port` 可改）
- **续期失败**：系统自动重试（下一轮扫描）；持续失败会通过通知规则告警
