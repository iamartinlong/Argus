# 域名管理（域名台账）

域名台账是「我关心的域名」清单：把域名作为**主数据**独立登记，与证书管理解耦。
覆盖状态由系统按关联证书**实时计算**，不需要手动维护域名与证书的对应关系。

## 为什么用域名台账

- **一眼看出哪些域名没有证书**：期望「必须有证书」的域名若没有有效证书，直接标红
- **到期预警更前置**：按域名维度展示剩余天数，比翻证书列表更直观
- **签发时少打字**：签发表单可从台账选择域名，不用每次手输

## 覆盖状态

| 状态 | 含义 |
|---|---|
| 已覆盖 | 有证书，且到期日还早（在续期窗口之外） |
| 即将到期 | 有证书，且已进入续期窗口（默认 30 天，与 `scheduler.renew_days_before` 一致） |
| 已过期 | 当前证书已过有效期 |
| 缺少证书 | 期望必须有证书，但没有任何关联证书 |
| 仅关注 | 期望状态为「仅关注」，不要求证书 |

覆盖状态是**计算字段，不落库**——每次打开列表实时重算，看到的永远是当前真实情况。

## 期望状态

| 期望状态 | 用途 |
|---|---|
| 必须有证书（默认） | 该域名必须有证书；缺失时状态标红，便于巡检 |
| 仅关注 | 只登记备忘（如暂未启用 HTTPS 的内部域名），不要求证书、不会标红 |

## 域名与证书怎么关联

不建映射表，读取时按两条规则实时匹配：

1. **精确关联**：签发/导入时绑定的域名（证书上的 `domain_id` 引用）
2. **域名匹配**：证书 SAN 覆盖该域名——精确匹配，或通配符父域匹配
   （如登记 `example.com`，`*.example.com` 签的证书也算覆盖）

「当前证书」取关联证书中**到期最晚**的一张，剩余天数按它计算；关联证书数为该域名关联到的证书总数。

## 列表

- 覆盖状态徽标、剩余天数、关联证书数、当前证书（域名/状态/渠道/到期日）
- 按状态筛选：全部 / 缺少证书 / 即将到期 / 已过期 / 已覆盖 / 仅关注
- 右上角刷新按钮重新拉取

## 登记 / 编辑 / 删除

| 操作 | 说明 | 权限 |
|---|---|---|
| 登记域名 | 填域名 + 期望状态，可选标签与备注 | admin / operator |
| 编辑 | 改域名、期望状态、标签、备注（域名不可与已有条目重复） | admin / operator |
| 删除 | 只删台账条目，**不影响已签发的证书** | admin / operator |

- 域名格式：字母 / 数字 / 点 / 连字符，可带 `*.` 前缀，≤253 字符
- 大小写不敏感，自动转小写；重复登记会提示「域名已在台账中」

## 与其他功能联动

- **签发表单**：证书管理 → 签发证书，域名输入框可从台账选择（也可直接手输，回车添加）
- **部署目标**：IIS / Nginx 场景配置 SNI 主机名时，同样可从台账选择
- **调度器**：自动续期只认证书，**不受台账影响**——台账是巡检视图，不参与续期决策

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/domains` | 台账列表（含实时覆盖状态与当前证书摘要） |
| POST | `/api/v1/domains` | 登记域名 |
| PUT | `/api/v1/domains/{id}` | 编辑 |
| DELETE | `/api/v1/domains/{id}` | 删除 |

读操作需要 `certificates:read`，写操作需要 `certificates:write`（API Token）；
Web 界面写操作限 admin / operator 角色。请求字段：`name`、`expected_status`
（`must_have_cert` / `monitor_only`）、`note`、`tags`。
